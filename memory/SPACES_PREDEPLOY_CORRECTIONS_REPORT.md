## 3. Search
- One box: **6-digit PIN** → existing PIN search (unchanged; old `?pin=` links work) [V]. Any other number → "valid 6-digit PIN" message [V].
- **Locality name** (≥3 letters) → official India Post localities whose official name **starts with** the text (case-insensitive; no fuzzy/approximate matching; max 30 shown) with district, state, PIN. Choosing one opens `/spaces?pin=<PIN>&locality=<official id>`: "Spaces in <locality>" (matched by official `locality_id`) + all PIN results [V].
- New public endpoint `GET /api/spaces/localities/name-search` (shared-secret, reference fields only) [V].

## 4. Draft withdrawal & duplicate safeguards
- **Withdraw**: owner-only, only a `draft` that was **never submitted** → soft status `withdrawn` (record, documents, history kept; no deletion). Submitted / changes requested / rejected / approved / unlisted cannot be withdrawn (409); other users 404 [V]. Withdrawn drafts don't count toward the 5-draft cap [V].
- **Duplicate warning** (warning only, never blocks): on the owner's Space page, lists the same owner's other Spaces at the **same official locality** with the same normalised address line or name; withdrawn ignored [V]. Deferred: warning inside the first-time `/app/spaces/new` flow (appears once the draft is reopened).
